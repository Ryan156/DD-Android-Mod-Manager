# Darkest Dungeon Mod Manager

A personal Android mod management tool built with **Kotlin and Jetpack Compose**, created to make managing mods for the unofficial Android port of *Darkest Dungeon* by Wicked more convenient.

Originally created to address my own mod management needs, this project is shared publicly in case it proves useful to other players.

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Local Storage:** Room, DataStore
- **File Management:** Android Storage Access Framework, DocumentFile
- **Networking:** Retrofit, OkHttp, Moshi
- **Asynchronous Operations:** Kotlin Coroutines
- **Serialization:** Kotlinx Serialization
- **Build System:** Gradle (Kotlin DSL)
- **Code Generation:** KSP
